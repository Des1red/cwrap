# Changelog
## [v2.9.0]

### Added
- `--uninstall` flag: removes the installed binary (`~/.local/bin/cwrap`) and the config directory (`model.ConfigDir()`) immediately, with no confirmation prompt.
- `bootstrap.Uninstall()`, `removeBinary()`, `removeConfig()` in `internal/bootstrap`.
- `--install` flag: allows explicitly (re)installing cwrap on demand, rather than relying solely on the implicit first-run bootstrap.
- `bootstrap.Init(force bool)`: when `force` is `true` on an already-installed system, prints a "reinstalling" message instead of silently returning.

### Changed
- `cmd.Execute()` now calls `manFlags()` before `boot()`. Previously `boot()` ran first, so `--uninstall` (and now `--install`) would trigger an implicit `bootstrap.Init()` reinstall before the flag was even handled — rebuilding the binary via `go build` just to delete it again. Flags are now resolved before any bootstrap side effects occur.
