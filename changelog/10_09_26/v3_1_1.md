# Changelog

All notable changes to the `report` package are documented in this file.

## [v2.9.1]

### Added
- `common.ReportWriter.KV(indent, width, key, format, args...)` — prints an aligned key/value line so consecutive fields land in a shared column.
- `common.JoinComma([]string) string` — comma-joins string slices for plain-text list output, alongside the existing `JoinSpace`.
- `common/color.go` — ANSI color helpers (`Bold`, `Red`, `Green`, `Cyan`) for terminal-only output. Colors auto-disable when `NO_COLOR` is set or stdout isn't an interactive terminal (piped, redirected, or captured by tests).
- Colored terminal recon summary: risk-based coloring on `yes`/`no` boundary flags, IDOR/admin surface and JS leak counts, the `High Risk Findings` block, and the save-status line. Color codes never reach the saved `.report` file — the summary writer (`printSummary`, stdout-only) and the file report writer (`writeFullReport`) are fully separate code paths.

### Changed
- Split the monolithic `report` package into subpackages: `common` (shared writer/helpers/color), `abnormal` (abnormal response dumps), `js` (JS finding filtering), `derive` (findings/next-steps derivation), `entity` (entity block + probe log rendering), with `report` as the orchestration root.
- Entity block vitals (`Probes`, `Methods`, `AuthLikely`, `CSRFPresent`, `Tech`, `Content`, `Statuses`, `Signals`) reformatted to an aligned key-value column instead of ad hoc `Line` calls.
- Replaced Go's bracket-style `%v` slice printing with comma-joined plain text throughout the entity block: `Methods`, `Tech`, `Signals`, identity tags, `CookieNames`, parameter tags, and `ObservedChanges` keys. `IdentityAccess`/`IdentityDenied` (maps) intentionally left as `%v` — no equivalent plain-text convention was defined for map output.
- Added blank-line separators before `Session:`, `Identities:`, `Parameters:`, `JS Intelligence:`, `Findings:`, and `Group Next Steps:`, each conditional on that section actually having content, so no empty section prints a stray blank line.
- `GLOBAL STATS` (file report) key column realigned to a consistent width, including the `Public endpoints:` line.
- Terminal summary: `Public endpoints:` deliberately left uncolored — a nonzero public-endpoint count isn't inherently risky on its own; the actual risk (a public *admin* surface) is already called out explicitly in `High Risk Findings`.

### Fixed
- Double blank line in the entity block when an entity has no session data: the vitals block previously emitted an unconditional trailing blank line, which stacked with the next populated section's own conditional leading blank. Session now follows the same "leading blank, only if content" pattern as every other subsection.
- Removed dead code left over from the pre-split monolith: `paramSourceLabel`, `copySet` (both unused).
- Removed a stale `// report/report.go` path comment in `report_summary.go`.
- Normalized filename casing across the split package files (previously a mix of PascalCase and lowercase segments).

### Verified
- `createReport` (formerly exported `CreateFileReport`) is intentionally unexported post-split; confirmed no external caller depends on it directly — all report generation goes through `CreateSummary`.
- `id.CookieNames` is `[]string`, compatible with the new `common.JoinComma`.
